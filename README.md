# Update Checker

Портативный аналог SUMo для **Windows 11**: показывает установленные программы, находит новые версии и обновляет их в один клик. Установка не нужна — один `.exe`.

## Скачать
Откройте раздел **Releases** и скачайте `UpdateChecker-Portable.exe`. Запускается двойным кликом, настройки хранятся в `settings.json` рядом с файлом.

## Возможности
- **Источники:** winget, Microsoft Store, Chocolatey, Scoop (включаются в ⚙ Настройки).
- **Выбор галочками ☑**, кнопки «Обновить отмеченные» / «Обновить все».
- **Закрытие процессов:** если программа запущена, спросит и закроет её (сначала мягко, затем принудительно). Режимы: спрашивать / автоматически / не закрывать.
- **📌 Закрепление версии:** закреплённая программа не обновляется.
- **↩ Откат** на предыдущую версию (winget, Chocolatey, Scoop) с выбором из списка версий; вкладка «История» с откатом в один клик.
- Фильтры, поиск, сортировка, статус «Нет в базах», счётчики, экспорт в CSV.
- Горячие клавиши: `F5` проверить, `Ctrl+F` поиск, `Ctrl+A` отметить все обновления, `Пробел` — отметить строку.

## Ограничения
- Проверяются программы, известные winget/Chocolatey/Scoop. Остальные помечаются «Нет в базах».
- Откат Microsoft Store невозможен. Для Chocolatey и части программ нужны права администратора (кнопка «🛡 От администратора»).
- `.exe` не подписан — SmartScreen может предупредить («Подробнее» → «Выполнить в любом случае»).

