# Update Checker

Портативная программа для **Windows 11**: показывает установленные программы, находит новые версии и обновляет их в один клик. Установка не нужна — один `.exe`.

## Скачать
Откройте раздел **Releases** и скачайте `UpdateChecker-Portable.exe`. Запускается двойным кликом (запросит права администратора), настройки хранятся в `settings.json` рядом с файлом.

## Возможности
- **Проверка при каждом запуске**, программы с обновлениями — сверху списка.
- **Источники:** winget, Microsoft Store, Chocolatey, Scoop (включаются в ⚙ Настройки; Chocolatey и Scoop необязательны — если установлены, находятся автоматически).
- **Выбор галочками ☑**, кнопки «Обновить отмеченные» / «Обновить все». Обновлённая программа сразу исчезает из списка.
- **Закрытие процессов:** если программа запущена, спросит и закроет её (сначала мягко, затем принудительно).
- **⏹ Остановить** — прерывает зависшую установку; при долгом молчании установщика программа предупреждает в журнале.
- **📌 Закрепление версии:** закреплённая программа не обновляется.
- **↩ Откат** на предыдущую версию (winget, Chocolatey, Scoop) и вкладка «История».
- Растягиваемый журнал, фильтры, поиск, сортировка, экспорт в CSV.
- Горячие клавиши: `F5` проверить, `Ctrl+F` поиск, `Ctrl+A` отметить все обновления, `Пробел` — отметить строку.

## Ограничения
- Проверяются программы, известные winget/Chocolatey/Scoop. Остальные помечаются «Нет в базах».
- Откат Microsoft Store невозможен.
- `.exe` не подписан — SmartScreen/UAC покажут «неизвестный издатель» («Подробнее» → «Выполнить в любом случае»).

## Сборка
```
build_exe.bat          # локально (нужен Python 3.9+)
```
Или создайте тег — GitHub Actions соберёт exe и опубликует релиз:

```
git tag v1.2.1 && git push origin v1.2.1
```
