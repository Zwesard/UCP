# Changelog

## 1.3.0
- Новая вкладка **«Драйвера»** (после «Программ»): проверка через Центр обновления Windows (WHQL), оценка риска, отметка галочками, «Обновить рекомендуемые», «📌 Не обновлять», сайт производителя, копия всех драйверов.
- Безопасность: точка восстановления и копия текущего драйвера перед установкой, установка по одному, предложение перезагрузки, откат драйвера (в т. ч. из истории).
- Драйверы проверяются автоматически после проверки программ (можно отключить).
- **История и откат:** клик по записи показывает её лог в журнале и подсвечивает ошибку (логи сохраняются между запусками).
- В CI добавлена проверка чтения драйверов на настоящей Windows.

## 1.2.0
- Запуск от имени администратора (манифест UAC в exe; при запуске из исходников — автоматический перезапуск).
- Автоматическая проверка при каждом запуске.
- Исправлено: проверка могла ничего не находить (stdin дочерних процессов, запасной разбор таблиц, диагностика в журнале).
- Список после проверки начинается с программ, которые нужно обновить; ручная сортировка сбрасывается.
- Обновлённая программа сразу пропадает из списка обновлений.
- Журнал: перетаскиваемая граница, прокрутка, очистка.
- Исправлено зависание установки: «⏹ Остановить», предупреждение о долгом молчании, таймаут.
- Поиск Chocolatey/Scoop вне PATH, пункт меню «Найденные инструменты».

## 1.0.0
- Первый релиз: winget, Microsoft Store, Chocolatey, Scoop; закрытие процессов; закрепление версий; откат; история.
