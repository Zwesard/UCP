## Update Checker 1.2.0 — portable для Windows 11

Скачайте **UpdateChecker-Portable.exe** и запустите двойным кликом. Установка, Python и другие программы **не нужны**. Настройки хранятся в `settings.json` рядом с exe.

### Что нового
- Запуск **от имени администратора** (запрос UAC при старте) — установщики больше не ждут подтверждения.
- Проверка обновлений **запускается автоматически** при каждом старте.
- Исправлена проблема, из-за которой проверка могла ничего не находить: теперь устойчивый разбор вывода winget и подробная диагностика в журнале.
- После проверки **программы с обновлениями — сверху списка**.
- Успешно обновлённая программа **сразу исчезает** из списка обновлений.
- Журнал можно **растягивать** (потяните границу над ним), есть прокрутка и кнопка «Очистить».
- Исправлено зависание на «Starting package install…»: кнопка **«⏹ Остановить»**, предупреждение при отсутствии вывода 90 секунд, защитный таймаут.
- Chocolatey и Scoop находятся автоматически, даже если их нет в PATH; пункт меню «Найденные инструменты».

> Windows SmartScreen / UAC покажет «неизвестный издатель», так как exe не подписан: «Подробнее» → «Выполнить в любом случае».
