## Update Checker 1.3.0 — portable для Windows 11

Скачайте **UpdateChecker-Portable.exe** и запустите двойным кликом. Установка, Python и другие программы **не нужны**. Настройки хранятся в `settings.json` рядом с exe.

### Что нового
- **Вкладка «Драйвера»:** поиск обновлений через Центр обновления Windows (только подписанные драйверы), риск 🟢🟡🔴, выбор галочками, «Обновить рекомендуемые», «📌 Не обновлять», сайт производителя.
- **Безопасность по умолчанию:** точка восстановления + копия текущего драйвера перед установкой, установка по одному, откат драйвера, «💾 Копия всех драйверов».
- **История и откат:** клик по записи открывает её лог в журнале и подсвечивает ошибку.

> ⚠ Драйверы — чувствительная область. Критичные (🔴: чипсет, система, накопители, прошивки) не входят в «Обновить рекомендуемые». Обновляйте драйверы, когда есть проблема или нужное исправление.
> Windows SmartScreen / UAC покажет «неизвестный издатель», так как exe не подписан: «Подробнее» → «Выполнить в любом случае».
